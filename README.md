# Spotify Data Analysis Project

## Project Overview

This project focuses on analyzing Spotify music data using **Python, Microsoft Excel, MySQL, and Power BI** to discover meaningful insights into music trends, artist performance, song popularity, and listening patterns.

The goal is to transform raw Spotify data into useful insights through data cleaning, exploratory data analysis, SQL queries, and interactive visualizations.

## 🛠️ Tools & Technologies

- **Python:** Data cleaning, preprocessing, and Exploratory Data Analysis (EDA).
- **Microsoft Excel:** Data organization, data cleaning, pivot tables, and preliminary analysis.
- **MySQL:** Data storage, querying, filtering, aggregation, and analysis.
- **Power BI:** Interactive dashboards, data visualization, and business insights.

## Project Workflow

### 1. Data Collection
- Import Spotify dataset.
- Understand the dataset structure and available columns.
- Identify important attributes for analysis.

### 2. Data Cleaning & Preprocessing – Python
- Handle missing and duplicate values.
- Check and correct data types.
- Identify inconsistencies and outliers.
- Prepare the dataset for further analysis.

### 3. Exploratory Data Analysis – Python
- Analyze song popularity and artist performance.
- Explore trends in track characteristics.
- Identify patterns and relationships between variables.
- Generate visualizations to understand the dataset.

### 4. Data Analysis – Microsoft Excel
- Organize and clean the dataset.
- Use sorting and filtering to explore records.
- Create pivot tables and charts.
- Calculate summaries and identify trends.

### 5. Database Analysis – MySQL
- Import Spotify data into MySQL.
- Perform data analysis using SQL queries.
- Use filtering, sorting, grouping, and aggregate functions.
- Apply JOINs, subqueries, and window functions where applicable.
- Identify top-performing songs and artists.

### 6. Dashboard Development – Power BI
- Connect and transform the dataset.
- Create interactive charts and visualizations.
- Build KPI cards and performance summaries.
- Develop an interactive dashboard to present key findings.

## Key Areas of Analysis

The project explores the following areas:

- Most popular songs on Spotify.
- Top-performing artists.
- Song popularity distribution.
- Trends in music releases.
- Relationship between song characteristics and popularity.
- Analysis of track duration.
- Artist and track performance comparisons.
- Music trends and patterns across the dataset.

*Note: The final analysis depends on the columns and information available in the dataset.*
